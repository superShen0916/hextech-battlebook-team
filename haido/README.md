# 海斗分5.2

海斗分依据本站已收录的有效海克斯大乱斗对局计算，不参考排位段位或隐藏分。唯一评分入口是 `haido/rating_lp.py`，产物为 `haido/haido_scores_lp.json`。

## 总分与计分区间

`总分 = 冻结历史基准 + 已结束各周累计涨跌 + 当前周分`。

历史基准只取北京时间2026-10-22 00:00之前的已收录可评分对局。此后对局按北京时间周一00:00至下周一00:00划分自然周，各计一次。新周只将周榜归零；总分保留过去各周的正负分，不自动恢复扣分。重复构建不会重复加分。

**规则按自然周分段**：北京时间2026-11-09 00:00 之前起始的周固定使用5.1参数，该周及之后的周使用5.2参数，由唯一入口的 `rules_for(周起始时间)` 选择。规则升级不改写已结束周分数；补局、纠错或明确排除仍可能修订对应周，但一律按该周当时生效的参数计算，不按账号、昵称或目标排名特判。

**BLG 夺冠周**：北京时间 2026-11-16 00:00（含）至 2026-11-23 00:00（不含）开局的可评分对局，胜负、表现与五杀全部按原贡献乘 2，包含扣分。与战斗之夜的 ×1.5 相乘，重叠时合计 ×3。晚采或补录仍以开局时间为准，活动结束后这一周按活动计分纳入累计，随后开局的对局恢复常规权重。

## 单场表现 v0.5

权重：伤害40%、参团15%、功能25%、存活10%、击杀10%。伤害占团队40%达到伤害单项100分，击杀占团队50%达到击杀单项100分：`min(100,250×伤害占比)`、`min(100,200×击杀占比)`。功能包括承伤、控制、队友治疗与护盾。MVP/ACE和海斗分使用同一表现来源；MVP/ACE没有额外固定加分。

冻结标尺：μ=51.4080594040618、σ=9.960125253702934、n=13831，来自已固定样本。文件 `data/haido-weekly-calibration-v04.json` 内部表现版本0.5，校验权重与占比门槛；缺失或失配停止，不自动重校准。现用历史基准也采用此标尺。

## 历史基准

```
z_i = (单场表现分 − μ)/σ
Z = Σz_i
D(Z) = Z（Z≥0）／0.4Z（Z<0）
B₀ = 1000 + [4×(W₀−0.6L₀) + 1.5×D(Z)]/(1+n₀/800) + 3×P₀
```

W₀、L₀、n₀只统计截止前对局。P₀为出现五杀的对局数，同局多次只计一局；没有截止前历史时基准为1000。历史基准使用未裁剪的z；周分才限制单局信号范围。

历史基准存于 `data/haido-baseline-v4.json`，所有玩家使用上述统一公式和冻结标尺。spec.version表示基准公式身份；普通构建核对完整spec，规则不一致时停止，必须通过已审阅迁移处理。文件名沿用既有持久状态名称，不代表另有评分入口。日常补局、新玩家加入或新周到来均不重算已有玩家基准。

显式迁移仅通过唯一评分入口的 `--rebuild-baseline-from-preview` 配合 `--baseline-backup`：必须与已审阅样本、标尺、玩家集合、逐人基准及旧基准哈希一致，并验证恢复ZIP。普通构建不传此参数。再次迁移需重新明确授权；不得删除基准后自动重建。迁移前应保存匹配的基准、标尺与评分源码恢复包。

## 单周公式

```
n = 本周可评分场数；c = n/(n+3)
k_i = 本周按开局时间正序的第几局
d_i = max(0.65, min(1, sqrt(12/k_i)))   # 5.1 历史周为 min(1, sqrt(12/k_i))，无下限
w_i = 1.5（周五20:00含至周六02:00不含，北京时间）／1（其余）
a_i = 2（BLG 夺冠周内开局）／1（其余）
g_i = clip((表现分−μ)/σ, −2, +2)
r_i = +1（胜）／−0.88（负）           # 5.1 历史周为 −0.95
p_i = 1.10g_i（g_i≥0）／0（g_i<0且胜）／0.62g_i（g_i<0且负）
五杀奖励_i = 2w_i×a_i × 该局五杀次数
δ_i = c×w_i×a_i×d_i×(6.30r_i+p_i) + 五杀奖励_i   # 5.1 历史周为 5.95r_i
周分 = round(Σδ_i, 1)
```

5.2 当前有效系数为：胜6.30、负−5.544（6.30×0.88），正表现1.10、输局负表现0.62。5.1 历史周仍为胜5.95、负−5.6525、正表现1.02、输局负表现0.68（B方案×0.85）；两套参数由 `rules_for` 按周选择，不按账号特判。5.2 以胜为主、不削弱好表现：正表现系数高于5.1，输局负表现系数低于5.1，未加权胜负零点由48.7%降到46.8%，上分体验更宽松。每次五杀独立+2、战斗之夜+3；双五杀普通+4、战斗之夜+6，不乘conf、场次递减或任何缩幅。胜负项未加权零点约46.8%胜率；实际结果还受表现、对局顺序、场次系数与战斗之夜影响，不保证50%胜率必然正收益。

胜负为主，个人表现保留：好表现能多加或少扣，表现较差的赢局不反扣；不因整周胜率低取消好表现。表现逐局累计，不除以周场数。每周前12局满权，其后平方根递减，胜负与表现同比缩小；5.2 起场次系数最低0.65（第29局起恒定），打得多不再一路衰减，5.1 历史周仍按 sqrt(12/k) 无下限递减。五杀奖励不乘c或d，同局多次五杀逐次累计。周分与总分均不设上下限。

同周新增对局会改变c，所以既有对局贡献可能更新。d只取该局周内序号；补入较早对局也可能修订序号。战斗之夜放大涨跌，不白送分。

## 逐局字段与公开投影

- `rating.base`：现用冻结历史基准；`settled_delta`：所有已结束周累计；`week.delta`：当前自然周分；`score`：三者合计。
- `settled_weeks`：逐周账本；周报与个人评分共用period_score，不另算一套。
- `calculation`：胜负、表现、五杀分项，置信系数、场次权重与标尺。展示分项因舍入可能有0.1差异。
- `recent[].rating_delta`：该局为所在周贡献的分值，包含战斗之夜和五杀；同周相加等于该周周分。每局显示1位小数，舍入残差分散处理，不集中到某一局。
- `rating_mult`：战斗之夜权重 1 或 1.5。`rating_championship_mult`：活动对局为 2，其余对局省略。`rating_volume_mult`与`rating_week_index`为该局的递减系数和周内序号。
- `rating_penta_bonus`：普通2×次数／战斗之夜3×次数，夺冠周额外乘2。奖励已包含在逐局分中，徽章保留2位小数。
- `snapshot.rating_rules`：由唯一评分入口输出真实系数与单场权重，页面直接使用。

10-22前对局计入基准，没有逐局周分字段。全历史可评分数<5未定级、5—99暂定、≥100稳定；缺失表现字段不当作0，重开与无法评分对局不计。总分榜按累计总分排序，同分并列；周榜只按当前周分。
