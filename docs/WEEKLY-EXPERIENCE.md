# 每周之星、海斗周报与氛围设置

前端实现位于 `work/players-preview-20261022`，周报由标准数据构建链生成。

## 大厅与周报

大厅默认按本周海斗分增量展示：正向涨分且全历史达到 5 场已定级的前三位进入领奖台，其余玩家接续排列。保持全部玩家入口、搜索、常看、按场次与按总分排序；搜索不重排全榜名次。正向玩家不足三人时留空并说明，不用掉分或未打玩家补星位。未定级、未打仍在完整名单中。

大厅三种展示由明确的按钮切换：“本周涨分榜”“海斗总分榜”“玩家卡片”。两种榜单共用领奖台与完整列表；总分榜按发布数据中的总分名次展示，同分并列，暂定玩家不因样本等级被强行放到稳定玩家之后，未定级排最后。总分卡片同时展示本周涨跌，玩家卡片也在海斗分下标出本周至今的正负变化；未打显示“本周未打 · +0 分”。个人档案原有周分强化为带单位的涨跌标签。

桌面冠军居中，左右亚军/季军同时缩小宽度与高度，增加台座、皇冠、英雄背景和玻璃反光。MotionCard.tsx 用鼠标位置驱动有界的轻微倾斜与反光，每帧最多一次绘制；移出重置，不改变点击与常看按钮。Top3采用紧凑卡片、头像、分数、台座与舞台布局，桌面舞台最大宽940px；手机冠军占一行并用紧凑横向身份/分数布局，左右二三名紧接着并排；触摸不启用鼠标倾斜。系统“减少动态效果”停用倾斜与皇冠动画。原玩家卡片也支持同一鼠标交互。

金银铜三种材质的边框与台座区分名次；冠军边框慢速流光、侧位悬浮时扫光。背景舞台光束与地面倒影独立于文字，装饰层不拦截点击；手机降低舞台光强并停用两侧光束漂移。减少动态效果同时停用边框流光与光束动画。舞台纯CSS与既有英雄素材实现，不增加大图/视频或外部动画依赖。

本周增量直接使用唯一评分入口导出的当前周分（单周不设上下限，含战斗之夜 ×1.5 权重）；总分累计已结束各周涨跌，单场权重与冻结基准保持不变。按北京时间周一零点重置，统计截至生成这份数据的构建时刻。无数据变化且复用已有产物时，仍展示原来的统计截止时间，不冒充已重新统计。相同周分按本周场次、固定公开 ID 排序。

总分名次按全部已定级玩家的显示分排序，同分并列。名次变化比较本周截至时刻与本周开始时的累计总分排名；本周新定级者标“新入榜”。此口径不是上一周周日末尾排名，也不是相邻两次发布的名次变化。周报对此有说明。

scripts/build_weekly.py 只读现役完整明细、完整快照与现有冻结基准，调用唯一评分入口 haido/rating_lp.py 的 period_score，其内部使用week_scores。每次标准完整/数据构建自动生成 public/api/weekly.json，带 build_id 和明确的 as_of_ms；新自然周生成新报告，旧周标记已结算。历史周使用目前已收录的有效战绩复算，补局可能修订历史周，不声称不可变的历史线上快照。评分启用前不伪造旧周报。

当前进行中与历史已结算周报均可切换、复制文字摘要。周报随标准更新链生成，浏览器不触发采集、托管或群消息发送。

## 回顾梗卡

沿用北京时间 18:00—次日 06:00 的当晚边界与 2—5 人同队交集。至少 3 场有效同队对局、表现分完整才评。当晚视角统计该玩家这一晚全部同队场次，各人按自己上场的场次算场均，不再切出「人数最多的固定阵容」——那样会把换过队友的场次整段丢掉。样本不足主力（最多场次那位）一半的人照常列出，标「轮换位」，不参与排名。多人回顾取所选玩家全部同队的交集，各人样本天然相同。不把对手当成队友。

用当前单场表现版本的场均分排名，上等马为最高、中等马为中间；最低那位场均不低于 50 分，或这段样本胜率超过 50%，就叫稳住位，否则才叫下等马——赢了不排下等马。最高与最低差不足 0.1 则不硬分；最高或最低相同（差不足0.1）共享对应称号。落败占比至少 60%、最低场均表现不足 40 且与最高差至少 10 时，才给下等马追加“甲级战犯”。这只是战绩玩梗，不判输赢责任，页面有展开规则。梗卡进入回顾页面、复制摘要与 PNG 分享图，链接恢复筛选的行为保留。

## 四款全站皮肤与 BGM

Atmosphere.tsx 与 weekly.css 提供海克斯鎏金、极地极光、虚空星云、祖安霓虹。皮肤和音量只存当前浏览器 localStorage，不变更玩家档案主题设置，不上传偏好。

音乐选择 Riot 官方 Sessions: Vi / Sessions: Diana，使用官方 SoundCloud 嵌入与 Widget API，保留播放器、曲名与作者、Riot 来源。参考 [Riot Sessions](https://www.leagueoflegends.com/en-us/event/sessions/) 与 [音乐使用说明](https://www.leagueoflegends.com/en-us/news/community/riot-music-creator-safe-guidelines/)。没有复制托管音乐文件。

每次打开网站默认关闭，用户点击开启后才加载音乐 iframe 与控制脚本；初始音量 18%，面板范围 0—35%，提供暂停、继续、关闭、切专辑与重试连接。离开可见页面主动暂停，回来不自行播放。关闭音乐移除播放器；只关闭设置面板不停止已开启的背景音乐。

第三方服务可达性与浏览器播放限制会影响音乐，提供状态和官方专辑入口；真实音频是否听见需单独实测，不用 mock 控制测试冒充听音验收。

## 海斗分规则入口

排行榜标题旁、个人档案分数旁和玩家卡片都有规则/计分明细入口。规则弹层先展示真实“基准+历周累计+本周=总分”，再展示当前周胜负/表现分项、实际系数与完整公式、已结算周账本。公式系数由Python评分入口导出，页面不自建第二套计分器；纯HTML/CSS排版，无外部公式服务或大依赖。支持Escape关闭、焦点往返与手机滚动。
