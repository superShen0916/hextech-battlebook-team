# 功能与兼容性要求

界面重构和性能优化必须保留以下功能及统计范围。功能移除或口径变更应作为明确的产品变更审阅。

| 模块 | 保留要求 |
| --- | --- |
| 玩家大厅 | 全部公开玩家、搜索、常看、周榜、总分榜、玩家卡片 |
| 个人档案 | 完整已收录历史、评语、六项指标、MVP/ACE、多杀、称号 |
| 六维雷达 | 单人展示、同类对比、两组图例、原始值与各自样本量；允许取消对比 |
| 英雄分析 | 常玩英雄入口、筛选、场次/胜率、装备及海克斯Top3、展开全部 |
| 装备与海克斯 | 图片、名称、场次、占比、样本覆盖、说明与相关对局跳转 |
| 对局列表 | 搜索、胜负、MVP/ACE、筛选、分页、单局装备与海克斯 |
| 十人战报 | 两队阵容、逐人表现、装备、海克斯及身份核验后的档案跳转 |
| 搭档与荣誉 | 队友搜索、升降序排序、关系样本、称号及20/30场门槛 |
| 成就 | 个人及搭档成就、代表局、缺失数据说明 |
| 当晚与多人回顾 | 北京时间18:00至次日06:00、2—5人同队交集、范围选择、分页与摘要 |
| 分享 | 个人、搭档和回顾的图片、链接及筛选条件恢复 |
| 周报与氛围 | 周榜、历史周报、皮肤、主动开启的BGM、减少动态效果支持 |
| 导航与移动端 | 锚点、浮动导航、回顶部、触摸操作及窄屏布局 |

首屏可以使用摘要并按需加载完整档案，但不能用最近若干场冒充全历史。雷达双方使用同一同类档案池尺度，缺失值不当作零。个人历史和部分同队样本必须明确区分，同队记录不代表预先组队。

分享图片只展示有限成员或对局时应标注截取，统计仍使用筛选内完整样本。非法条件或缺失关联必须明确提示，不能替换成另一玩家、另一局或另一份回顾。超时、重试和版本一致性保护属于功能要求。
