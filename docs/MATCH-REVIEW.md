# 十人战报

战报由高光、成就代表局、搭档回顾和历史列表打开。保留当前玩家的赛后记录，并展示完整两队阵容：姓名、英雄、KDA、伤害与占比、承伤、海克斯，以及可展开的装备、队友治疗/护盾、金币和评分。已建档玩家可跳转个人页。

## 数据与关联

唯一前端的 `prepare-match-details.py` 从已收录原始摘要和唯一运行库读取数据，构建过程不触发采集。公开对局ID沿用稳定哈希；旧ID使用时间、时长、英雄、KDA及胜负等签名唯一匹配。缺失、多候选或身份歧义拒绝关联，不凭同名猜人。

输出为 `public/matches/index.json` 和单局白名单明细。索引及指定对局在打开战报时按需加载，不把全部十人数据塞入首屏。页面核对日期、时长、英雄、KDA、胜负及两队人数；加载失败可重试，缺少关联时保留个人记录并显示待补。

网页公开明细不包含客户端认证、连接配置或原始账号身份。开发Release包含完整游戏数据，与网站白名单投影分开。战报是赛后记录，不提供录像、逐帧时间轴或技能轨迹。

## 评分

单场表现统一调用 `app/awards.py`。逐人字段包括版本、分数、奖项、队内名次及并列标记；比赛字段说明是否可评分及原因。无效或缺失数据不伪造零分。MVP/ACE属于工具自评，非游戏官方奖项。

## 维护与验证

前端组件为 `src/MatchRoster.tsx`，样式为 `src/match-roster.css`。修改通过 `Workflow.cmd prepare` 验证关联、评分、导航及完整数据门禁；不直接手改生成的JSON。
