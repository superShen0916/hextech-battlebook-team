# 外部分数接入

Hexdata外部分数与本站海斗分是不同来源。本站评分规范见[海斗分](../haido/README.md)；外部估计值必须标注来源、查询时间和数据截止时间，不称为官方隐藏分或实时结果。

## 输入与投影

`data/hexdata-ratings.json` 保存导入状态，`app/hexdata.py` 负责读取与白名单投影。导入通过 `scripts/import_hexdata_ratings.py` 校验唯一游戏身份，不通过昵称在浏览器二次匹配。公开字段由服务端投影决定，原始查询资料和本机凭据不提交到Git。

| 状态 | 显示 |
| --- | --- |
| `estimated` | 估计分及有效来源信息 |
| `pending` | 待查询 |
| `not_queried` | 未查询 |
| `unavailable` | 暂不可用 |

非estimated状态不能显示伪造的分数或时间，排序时放在有效数值之后。缺失值不是零；旧待查条目不覆盖已查询结果。

## 展示约定

账号分数从当前对象的 `rating` 读取，英雄筛选不改变账号分数。`top_percent` 已是百分数，不再乘100；时间按北京时间展示。来源未给出截止时间时保持空值，不以查询时间代替。

外部输入更新后仍需通过标准构建和原应用发布流程，网页不直接读取本机文件或自动采集外部分数。
