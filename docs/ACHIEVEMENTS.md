# 成就规则

本馆趣味成就，非游戏官方奖项。仅按已收录的有效标准海克斯样本计数，全部门槛包含等于。每系列依次铜/银/金；已到金章显示当前实际值，缺记录保留待补，不当0分。不记或猜首次达成日期，也不把未点亮当成完整生涯未达成。

| 系列 | 铜 / 银 / 金门槛 | 依据 |
| --- | --- | --- |
| 大乱斗常驻人口 | 100 / 500 / 1000场 | summary.games |
| 这把分我先上 | 50 / 200 / 500胜 | summary.wins |
| 这把真是我 C | 10 / 50 / 100次 | awards.mvp，工具自评 |
| 尽力局局长 | 10 / 50 / 100次 | awards.ace，工具自评 |
| 英雄池还是海 | 10 / 30 / 60英雄 | champions中至少1场有效局的英雄 |
| 这英雄有身份证 | 20 / 50 / 100场 | 单英雄有效场次最大值 |
| 五杀，截图！ | 1 / 5 / 20次 | summary.penta_kills；同局可多次 |
| 伤害面板有话说 | 单局10万 / 20万 / 30万 | 有效recent.player.damage最大值 |
| 人头你拿，助攻归我 | 单局30 / 50 / 70助攻 | 有效recent.player.assists最大值 |
| 对面技能我全吃 | 单局10万 / 20万 / 30万承伤 | 有效recent.player.taken最大值 |
| 怎么又是你 | 20 / 100 / 500场同队 | 来源关系有效场次 |
| 咱俩有点说法 | 10 / 50 / 200场同队胜利 | 来源关系有效胜场 |
| 赢了就不许散 | 3 / 5 / 8连胜 | 完整关联的已收录有效同队局按时间排序，非未收录生涯连胜 |

搭档每对只列一次，独立个人历史来源优先，再按关系场次与稳定ID选择，左右对调不改口径。不混合不同范围的关系汇总，不从旧样本跨源ID猜交集；逐局数不等于关系有效场次时，连胜待补。同队不代表预先组队。

代码：lib/achievements.ts（统一规则）、lib/pair-story.ts（同队来源）、src/Achievements.tsx（个人/搭档/成就馆）、src/LobbyNav.tsx。分享页通过Vite构建插件复用同一份规则；playerVerdict/share-style仅按当前范围生成点评，不把正向文案当精确战术结论。

## 连续表现与治疗成就

成就共16个系列，每系列铜、银、金三个等级。

| 成就 | 铜 / 银 / 金 | 计算与缺失处理 |
| --- | --- | --- |
| 把把 C | 2 / 3 / 5 连场自评MVP | 已收录有效局按时间排序；只计MVP，ACE不算，缺评分中断，缺日期不推算 |
| 下把一定 | 3 / 5 / 8 连败 | 已收录有效局按时间排序，缺胜负中断，缺日期不推算 |
| 兄弟别急，我有奶 | 单局1万 / 3万 / 6万队友治疗 | 仅对队友治疗，不含自疗和护盾；缺失待补 |

连续性仅描述已收录样本，不声称未收录的对局也连续。点击可查看档案范围和代表局，不把代表局当成精确首次解锁时刻。verify-achievements.mjs覆盖倒序输入/ACE与MVP区分/缺评分中断/缺结果中断/无效局排除/缺日期/治疗口径测试。
